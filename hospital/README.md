# Hospital BIM in AR

A second demo in this repo, separate from the original AEC 450 app (nothing outside `hospital/`
is changed). It shows the Autodesk hospital sample (Revit 2018) as WebAR on a printed sheet, with
the same open-source 8th Wall engine and A-Frame as the parent app.

**How it works:** print `print/hospital-poster-letter.pdf` or `print/hospital-poster-a4.pdf` at
100 % and scan the QR code. The sheet's site plan is a true-scale aerial render of the model, so
the hospital rises exactly out of its own picture.

## What the app shows

- **Seven sub-models**, each one a toggle:
  - Architecture, Structure, HVAC, Piping & Plumbing, Electrical, Fire Alarm, Site & Landscape.
  - Double-tap a sub-model to isolate it.
  - Turning on an MEP sub-model ghosts the architecture automatically (**X-ray**).
- **Systems:** colours ducts and pipes by MEP system: supply, return and exhaust air, hot and
  chilled water, medical gas, oxygen, vacuum, cooling tower, sanitary and domestic hot water. A
  legend appears while it's on.
- **Section:** cuts the whole model 1.2 m above any level, the way a Revit plan view does.
- **Original / Enhanced / Compare:**
  - *Original* is the raw Revit export: Revit shading colours and RPC placeholders.
  - *Enhanced* adds:
    - PBR materials with CC0 textures from Poly Haven.
    - Sky reflections and sun shadows.
    - Modelled trees, shrubs, trucks and the air-ambulance helicopter.
    - A site base with lawn, paving and the sunken loading dock.
  - *Compare* draws both at once, with a draggable divider between them.
- **Tap to identify:** tap any element to see its type, category, discipline, level, system and
  Revit ID.
- **Desktop preview:** add `?mode=3d` to the URL. Drag to orbit, scroll to zoom, and right-drag to
  pan.

## Pipeline

```
2018_Hospital_<Model>.rvt ──DDC RvtExporter──> .dae + .xlsx  (~/DDC_Tools/work/hospital)
  pipeline/fetch_textures.py ─> src/assets/tex/*        CC0 PBR textures (512 px), sky env, procedural panel/ceiling/PV
  pipeline/build_hospital.py ─> src/assets/<disc>.glb    one file per sub-model, meshopt-compressed (gltfpack)
                                src/assets/<disc>.json   element table for tap-to-identify
                                src/assets/scene.json    looks (materials), MEP systems, levels, placements
  pipeline/make_entourage.py ─> src/assets/entourage.glb trees/shrubs/vehicles (instanced) + site base
  app ?mode=3d&shot=...      ─> pipeline/out/shots/*    poster renders (dev server only)
  pipeline/make_poster.py    ─> print/*, src/assets/target-placement.json
  npx @8thwall/image-target-cli ─> image-targets/hospital-poster*
```

- **Per-face materials:** wall faces whose rays escape the building get the exterior finish (brick,
  metal panel, CMU, limestone). Faces facing inward get paint.
- **Design colours kept:** metal panels and mullions keep the designer's Revit colour under the
  PBR finish.
- **Mesh reduction:** over-detailed families (toilets, shower heads, grab bars, chairs, louvers)
  are reduced to triangle budgets that are invisible at tabletop scale. Round ducts and pipes keep
  45–50 % of their triangles.
- **File size:**
  - 2.45 M triangles and 19 MB of GLB in total.
  - The first view (architecture, site, entourage and textures) is about 9.5 MB.
  - The other sub-models load in the background.

To rebuild after a model change, run:

```bash
python -I pipeline/fetch_textures.py
python -I pipeline/build_hospital.py
python -I pipeline/make_entourage.py
# with `npm run serve` running, re-render the poster images (see runShot in src/app.js), then:
python -I pipeline/make_poster.py
printf '%s\n' print/hospital-poster.png 1 y image-targets hospital-poster | OVERWRITE_FILES=true npx @8thwall/image-target-cli@latest
```

## Develop and deploy

```bash
cd hospital
npm install          # gltfpack; webpack comes from the parent repo's node_modules
npm run serve        # http://localhost:8034/?mode=3d
npm run build        # -> hospital/dist
node scripts/deploy-pages.js   # adds /hospital/ to gh-pages; leaves the original demo alone
```

The QR code points to `https://salarka.github.io/bim-ar-8thwall/hospital/`. It only works once the
demo has been deployed.
